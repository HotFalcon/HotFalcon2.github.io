How to use

Your shortcut is a bookmark that updates the open ticket page. Set it up once using the steps for your device.

  1. Create & copy your shortcut

    Choose your layout and fill in the ticket details above. Tap Create my shortcut, then Copy shortcut. Wait for the “Copied!” confirmation.

  2. Make a Safari bookmark

    Open any webpage in Safari. Use Page Menu → Add Bookmark to (or Share → Add Bookmark). Name it Ticket Editor, save it in Favorites, and tap Save.

  3. Replace the bookmark’s address

    Open Safari’s Bookmarks. Press and hold Ticket Editor, then choose Edit. Delete its entire URL and paste the copied code in its place. Keep javascript: at the beginning, then save.

  4. Run it on your ticket

    Sign in to SeatGeek in Safari and open the ticket details. Once the tickets load, open Bookmarks and tap Ticket Editor. A message tells you how many tickets were updated.

This runs on a browser ticket page. It won’t run inside the SeatGeek app, Apple Wallet, a screenshot, or a PDF. Safari menus vary by version. Bookmark help

  1. Create your shortcut

    Choose your layout, enter the ticket details, and click Create my shortcut. A copy button and bookmark link will appear below the form.

  2. Drag it to your bookmarks bar

    Show your browser’s bookmarks or favorites bar. Drag the Drag to bookmarks bar link onto it. Drag the link rather than clicking it on this page.

  3. Or save it manually

    If dragging doesn’t work, click Copy shortcut. Create a bookmark for any webpage, name it Ticket Editor, and edit it. Replace its entire URL with the copied code, including javascript:, then save.

  4. Run it on your ticket

    Sign in to SeatGeek in the same browser and open the ticket details. Let the tickets load, then click your saved bookmark. A message confirms how many tickets were updated.

The code belongs in a bookmark’s URL, not directly in the address bar. Some browsers or managed devices may block these shortcuts.

Need help?

Nothing changed. What should I check?

Make sure the ticket is open in your browser and the bookmark URL contains the complete code, starting with javascript:. Try Standard first; if no tickets match, choose Alternate and create a new shortcut. Replace the old bookmark code before trying again. SeatGeek layout changes can affect compatibility.

Why were only some tickets updated?

The shortcut starts with the first matching ticket and updates up to your chosen count, using consecutive seat numbers. It can only change tickets already loaded on the page—it doesn’t swipe through or load more cards. Check the result message and each ticket.

How do I change or reset the details?

Reload the ticket page to restore its original details. To use new settings, update the form, create a new shortcut, and replace the code in your saved bookmark. Changing the form alone doesn’t update a bookmark you already saved.

How do the Braves options work?

In Standard, turn on Braves ticket. Added value applies to each selected ticket; 0 hides that line. Season ticket holder → Yes adds “MB$A-List Discount”. The optional section title adds another line. These settings replace the selected tickets’ extra-detail rows.

What changes on the ticket?

Only the displayed text on the open page. The barcode, valid seat, ownership, and account records stay the same. Reloading the page restores the original details.
